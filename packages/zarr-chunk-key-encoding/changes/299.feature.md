Initial release of `zarr-chunk-key-encoding`: the `ChunkKeyEncoding` abstract
base class, the spec-defined `DefaultChunkKeyEncoding` and
`V2ChunkKeyEncoding`, and JSON round-tripping
(`chunk_key_encoding_from_json`, `parse_chunk_key_encoding`) built on the
`zarr-metadata` types. Name dispatch is over the closed set the Zarr v3 core
spec defines: there is no registration API and no entry point group, because
the machinery third-party encodings need is common to all five v3 extension
points and belongs in one shared package rather than reinvented per package.
