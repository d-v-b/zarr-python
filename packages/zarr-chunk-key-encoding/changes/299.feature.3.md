Added `ChunkKeyEncodingSupport`, recording whether a registered encoding is
defined by the Zarr v3 core spec (`CORE`), registered in `zarr-extensions`
(`EXTENSION`), or neither (`CUSTOM`, the default). Encodings declare their
level as a class attribute, `registered_chunk_key_encodings` takes a
`support=` filter and `get_chunk_key_encoding_support` looks one up, so a
consumer can gate extension or local encodings behind a feature flag.
Registering a class that claims `CORE` for a name the spec does not define is
an error, so the level cannot be self-asserted.
