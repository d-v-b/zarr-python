Entry-point discovery no longer lets one broken third-party package break the
registry. A plugin that fails to import, does not load to a `ChunkKeyEncoding`
subclass, or is otherwise rejected is now skipped with a
`ChunkKeyPluginWarning` instead of raising: because discovery runs lazily from
any lookup that misses, raising turned an unrelated plugin's breakage into a
hard error on every such lookup, and stranded the entry points enumerated
after it. Discovery also routes through `register_chunk_key_encoding` rather
than writing to the registry directly, so an entry point cannot bypass its
checks — notably the one preventing a plugin from claiming the `CORE` support
level for a name the spec does not define.
