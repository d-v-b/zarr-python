Added `RegularDimensionGridLike`, a structural protocol for grids whose chunk
`k` starts at `k * size` and declares `size` elements, with `extent` clipping
only the last chunk. The private, opt-in `zarr_indexing._execution` prototype
uses it to plan dense sorted coordinate gathers without a per-axis table; it
lowers prepared selections to the four-field chunk rows Zarr's codec pipeline
consumes, and is not a public API.
