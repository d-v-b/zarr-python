Add `zarr-storage`, a new package with a Zarr-agnostic key-value storage API: a `Store` view over memory, local-filesystem and obstore backends, with sync and async methods, conditional reads and writes (`get_if_changed`, `put_if_absent`, `put_if_match`, `delete_if_match`), byte-range reads and reads into caller buffers. It ships a conformance suite in `zarr_storage.testing` that any backend can run.
