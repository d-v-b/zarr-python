Fixed orthogonal-index writes (``arr.oindex[...] = value``) to sharded arrays when more than one dimension is indexed with an integer array. The selection reaches the shard as a coordinate selection, whose inner chunk projections index a flat output, but the written value was still the N-D block from the outer indexer, so the write raised ``IndexError`` or a broadcast ``ValueError`` whenever a shard received more than one element per dimension. The value is now flattened to match, mirroring what the decode path already does.
