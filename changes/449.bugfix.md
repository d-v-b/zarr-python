Fix array metadata validating each codec against the stored chunk grid even after a `TransposeCodec` filter had permuted the chunk shape. A sharding serializer whose inner chunk shape divided only the stored grid was accepted, then read back wrong data. A valid one was rejected. Codecs gain a `resolve_chunk_grid` method, the chunk-grid counterpart of `resolve_metadata`, which `TransposeCodec` uses to permute the grid.
