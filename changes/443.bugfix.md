Indexing an array with a Boolean NumPy array now selects what NumPy selects. That covers a mask over the leading axes (for example a `(2, 3)` mask on a `(2, 3, 4)` array), an empty mask whose length is 0 along an axis, and a full-shape mask on an array with a zero-length axis. Orthogonal selection also accepts an empty Boolean array and no longer fails on a zero-length dimension. A Boolean array with more than one dimension inside a selection tuple, which is not supported, now raises an error that says so instead of one about orthogonal selection.
